{% comment %} Eén aanklikbare kaart in een overzicht (panels/posts.html): eventueel een beeld, een soort-label, een metaregel, een titel, een korte tekst en een leeslink. De hele kaart is de link. Pass: href, title, text, cta, aria, label, meta, meta2, datetime, image, webp, alt, ratio, variant, type. `meta` is de regel boven de titel. Staat er ook een `datetime` bij, dan komt die in een -element; anders is het gewone tekst. Zo draagt dezelfde kaart een publicatiedatum of bijvoorbeeld een opdrachtgever. `meta2` is een tweede gegeven op diezelfde regel (bijvoorbeeld de leestijd). `variant="featured"` maakt er een bredere uitgelichte teaser van. `type` zet data-verhaal-type op de kaart, voor het filter op /verhalen/. {% endcomment %}
